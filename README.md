# Geoconnex Explorer

A map-based browser for the [Geoconnex](https://geoconnex.us) knowledge graph.

- Click a river (mainstem) on the map to list the features linked to it
- Search features by name across all Geoconnex sources
- Inspect any feature's datasets, raw RDF properties, and SPARQL query
- Export feature and dataset lists as CSV

## Development

```sh
npm install
npm run dev
```

Pushes to `main` deploy to GitHub Pages.
